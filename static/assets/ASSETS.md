# Illustration notes

`hatti-landscape.png` and `founder-story.png` were generated with OpenAI image generation for this project on 3 October 2026 (local date).

The founder strip was requested by Siva Babu and uses his public GitHub profile photograph as a likeness reference. The reference photograph is not bundled. It shows three conceptual scenes: connection to home, the language gap for children abroad, and building a playful bridge through Hatti Quest. Other people are fictional. The scenes make no claim about Siva's actual relatives, residence or personal events.

The landscape depicts an imaginative hill village inspired by the Nilgiri region. It is not an authoritative reconstruction of Badaga architecture, dress, sacred practice or geography.
